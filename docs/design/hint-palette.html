Sigil hint palettes

Every candidate chip drawn over the three surfaces hints really land on: a light page, a dark page, and a busy image (like your Chrome theme). The system mode picks the palette, but the page underneath can be either, so a good chip has to hold up on all three.

Swatches marked new are deeper shades I'd add to the base five. Text on a 12pt chip needs real contrast: Ivory on Evergreen is only 4.35:1, Ivory on Forest is 6.5:1, Ivory on Pine is 9.1:1.

Style changes in every candidate (except “Current”)
  • No gradient or gloss. A flat fill, a 1px hairline edge and a soft 1–2px shadow. That's most of what makes it read as modern.
  • The typed prefix gets an accent colour (Terracotta/Clay or Sage) instead of just fading, so you can see what you've typed.
  • Same monospace bold, same size and padding, so hint density doesn't change.
